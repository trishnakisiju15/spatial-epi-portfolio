Nepal dengue and the Suitable Conditions Index (SCI), 2022–2024

Keywords: dengue, Suitable Conditions Index, Aedes aegypti, Aedes albopictus, spatiotemporal analysis, INLA, Nepal

Key findings
  • Dengue incidence in Nepal is spatially clustered (Moran’s I 0.429); the Terai has the highest climate suitability.
  • Higher SCI went with higher incidence for BDA- and PWDA-SCI in both species (for example RR 1.52 to 2.88 in district models).
  • Monthly model: Ae. albopictus RR 1.05 per 10 points of suitable days at lag 1 (1.02–1.07).

The SCI is the percentage of days when temperature stays inside the range that Aedes aegypti (17.05–34.61 °C) or Aedes albopictus (15.84–31.51 °C) tolerates. A high SCI means the climate allows transmission; it does not show that mosquitoes are present. The analysis tests whether SCI goes with higher dengue incidence across districts (Models A and B) and over months (Model C).

Three index versions

BDA-SCI is the percentage of suitable days (temperature only). PWDA-SCI multiplies it by mean daily rainfall. WWDA-SCI multiplies it by the district’s waterbody fraction from Google Earth Engine (Dynamic World).

Reading the results

A relative risk (RR) of 1.05 is a 5% higher dengue rate per unit of the predictor, and an interval that includes 1 means the association is unclear. Lower AIC or WAIC means better fit. Negative binomial models use log population as an offset, so they compare rates, not counts.

fit_nb <- function(sci_var, adjust) {
  covs <- if (!adjust) ""
          else if (grepl("^pwda", sci_var))
            " + water_prop + log_elev + log_dens"
          else " + precip_cat + log_elev + log_dens"
  f <- as.formula(paste0("cases ~ ", sci_var, covs,
                         " + offset(log(pop))"))
  MASS::glm.nb(f, data = dat_z)   # mgcv backup if needed
}

run_inla_A <- function(sci_var = NULL) {
  rhs <- paste(c(sci_var, "log_elev_z", "log_dens_z", "rain_z",
    "f(id, model='bym2', graph=g, scale.model=TRUE)"),
    collapse = " + ")
  inla(as.formula(paste("cases ~ 1 +", rhs)),
       family = "nbinomial", data = dat, E = dat$pop,
       control.compute = list(waic = TRUE))
}

# Model B: high vs low incidence districts
dat$high <- as.integer(dat$ir > median(dat$ir))

# Leave-one-district-out logistic regression
loo_blr <- function(sci_var, adjust) {
  covs <- if (adjust) " + log_elev" else ""
  form <- as.formula(paste0("high ~ ", sci_var, covs))
  p <- sapply(seq_len(nrow(dat)), function(i) {
    m <- glm(form, family = binomial, data = dat[-i, ])
    predict(m, newdata = dat[i, ], type = "response")
  })
  cls <- as.integer(p > 0.5)
  data.frame(
    AUC_loo  = auc(roc(dat$high, p)),
    sens_loo = mean(cls[dat$high == 1] == 1),
    spec_loo = mean(cls[dat$high == 0] == 0),
    acc_loo  = mean(cls == dat$high)
  )
}

# Model C: monthly spatiotemporal (primary = lag 1, all years)
run_inla_f2 <- function(d, sci_col = NULL) {
  d$dy <- as.integer(factor(paste(d$id, d$year)))
  if (!is.null(sci_col)) d$sci <- d[[sci_col]] - mean(d[[sci_col]])

    if (!is.null(sci_col)) "sci",
    "rain_z1", "rain_z1_sq",

    "f(id, model='bym2', graph=g, scale.model=TRUE)",
    "f(dy, model='iid')"), collapse = " + ")
  inla(as.formula(paste("cases ~ 1 +", rhs)),
       family = "nbinomial", data = d, E = d$pop,
       control.compute = list(waic = TRUE))
}

Weather and the SCI

Five sampling points per district were drawn with probability proportional to WorldPop population, so weather describes where people live. Daily minimum and maximum temperature and rainfall were downloaded for 1 October 2021 to 31 December 2024 (1,188 days at all 77 districts) so lagged values exist from January 2022. Points in the same small district may share nearly the same weather because the reanalysis grid is about 10 km.

BDA-SCI for Ae. aegypti ranges from 0 to 63.5% (median 35.6%), and for Ae. albopictus from 0 to 48.8% (median 31.6%). The highest values are in the southern Terai.

Conclusion

Clustering

  • Incidence is clustered (Moran’s I 0.429, p = 0.0001, and 0.41 to 0.51 in each year). Local Moran found 14 High-High and 7 Low-Low districts, with hot spots in the central hills.
  • The Terai has the highest SCI: Jhapa (63.5%), Morang, Sunsari, Saptari and Siraha for Ae. aegypti.

Model A: district totals

  • Higher SCI went with higher incidence for BDA-SCI and PWDA-SCI in both species, unadjusted and adjusted (for example BDA Ae. aegypti RR 1.52 unadjusted, 2.68 adjusted; PWDA Ae. albopictus 2.05 and 2.39).
  • WWDA-SCI was significant only after adjustment (1.44 and 1.54).
  • With the spatial (BYM2) model, RR per 10 points was 1.51 and 1.53, with intervals above 1.

Model B: high versus low incidence

  • Odds ratios were significant for BDA-SCI and PWDA-SCI in both species (adjusted: 10.37 and 8.48 for Ae. aegypti, 3.87 and 5.28 for Ae. albopictus), and not significant for WWDA-SCI.
  • Best leave-one-district-out AUCs were about 0.83 (PWDA Ae. aegypti adjusted and PWDA Ae. albopictus unadjusted).

Model C: monthly model

  • Ae. albopictus (primary, lag 1, all years): RR 1.05 per 10 points (1.02–1.07), Δ WAIC 10.88.
  • Ae. aegypti (primary): RR 1.03 (0.99–1.06), not significant. Without 2022 it was 1.05 (1.01–1.08).
  • Zero-inflated models gave almost the same RRs.
