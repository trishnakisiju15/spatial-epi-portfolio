# Spatial epidemiology portfolio

Bayesian spatial and spatiotemporal analyses using R and INLA.

**Live site:** https://trishnakisiju15.github.io/spatial-epi-portfolio/

| Analysis | Setting | Focus |
|----------|---------|--------|
| COVID-19 | Nepal (77 districts) | Incidence clustering and determinants |
| Pneumonia | Korea (250 municipalities) | Mortality and spatial risk |
| Suicide | Korea, 2010–2021 | Spatiotemporal trends by age |
| Air pollution | Korea, under 65 | Long-term exposure and mortality |
| Dengue SCI | Nepal, 2022–2024 | Climate suitability and incidence |
